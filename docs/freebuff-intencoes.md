# Freebuff — Intenções de Produto

> Fonte consultada: https://freebuff.com  
> Objetivo: traduzir o que a página apresenta como produto e deixar registrado como lista de intenções para o ecossistema OmegaDrakon / Freebuff local.

---

## 1. O que a página apresenta

O site se posiciona como um assistente de programação 100% gratuito, com a ideia de “poder de coding dirgível” financiado por anúncios de texto.

Ele traz quatro produtos principais:

- **Freebuff CLI**
  - Agente de programação direto no terminal.
  - Sem API key e sem cartão de crédito.
  - Posiciona-se como alternativa gratuita a outras ferramentas de coding.

- **Freebuff Desktop**
  - Aplicativo para macOS, Windows e Linux.
  - Execução de agentes de programação em paralelo, cada um em seu próprio workspace.
  - Sem API key e sem cartão de crédito.

- **Freebuff Web**
  - Construtor web de aplicações full-stack.
  - Hospedagem gerenciada por agentes.
  - Do prompt até um app vivo em uma URL própria.

- **Freebuff Cloud**
  - Agente de programação em um IDE cloud.
  - Conecta-se a repositórios GitHub, públicos ou privados.
  - Editor, terminal e sandbox real.
  - Sem instalação local.

O site também menciona:

- **Freebuff Chat**
  - Chat de IA gratuito com foco em pesquisa e raciocínio mais profundo.
  - Posiciona-se como alternativa a outros planos pagos de chat/assistente.

E uma ideia central de negócio:

- O modelo é financiado por anúncios de texto.
- A proposta é “matar” assistentes de coding pagos, mantendo o projeto do usuário.

## 2. Lista de intenções

### 2.1 Assistente que conversa
- Oferecer um chat de assistente com capacidade de pesquisa e raciocínio.
- Usar conversa como entrada para tarefas de programação e de análise.

### 2.2 Assistente que programa
- Permitir que o usuário descreva mudanças e o agente edite código.
- Ler arquivos, mapear rotas/estrutura e executar alterações.
- Rodar testes e relatar resultados.
- Gerar diffs, commits e arquivos modificados.

### 2.3 Ambientes de execução
- Ter suporte a execução no terminal, na desktop e na cloud.
- Cada ambiente deve ser acessível sem dependência gratuita obrigatória de chaves externas, segundo a página.
- Suporte a execução paralela quando houver workspace múltiplo.

### 2.4 Construção web e full-stack
- Permitir criar aplicações web a partir de prompts.
- Oferecer visualização prévia do resultado.
- Disponibilizar publicação/hospedagem do app em uma URL.
- Focar em builds completas, não só em trechos de código.

### 2.5 Conectividade com repositórios
- Conectar-se a repositórios GitHub, públicos ou privados.
- Ler contexto do projeto.
- Aplicar mudanças e devolver o que foi alterado.

### 2.6 Não-мayneiras declaradas
- Sem assinatura.
- Sem configuração inicial obrigatória.
- Sem API key.
- Sem cartão de crédito.
- Sem lock-in, segundo a página.

### 2.7 Financiamento e modelo
- Suporte por anúncios de texto.
- Modelos de IA financiados dentro do produto.
- Proposta de economia comparada com ferramentas pagas.

## 3. O que isso significa para OmegaDrakon

- O Freebuff, como visto no site, não é um sistema “mundial” de dados públicos ou climáticos.
- Ele é uma linha de produtos de coding agent + chat + builder + cloud.
- Se o objetivo é trazer essa intenção para cá, eu não vou implementar a versão comercial pública do Freebuff.
- Eu posso, se quiser, usar essa lista como guia para adaptar o OmegaDrakon numa direção parecida, focada no que cabe num assistente local ou num ecossistema próprio.
