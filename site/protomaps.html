ProtoMaps Offline

Mapa vetorial offline usando MapLibre GL JS e tiles ProtoMaps. Esta página é a tarefa de dev decidida em 12/10 — o container ProtoMaps do NOMAD foi convertido em página web no site Omega Drakon, mantendo a capacidade de mapa offline sem depender de container dedicado.

Visualização Offline

Controles e Informações

  • Tiles: ProtoMaps (PMTiles vetoriais) quando o arquivo local existe; senão, raster OSM
  • Verificando tiles…
  • Estilo: Estilo base OSM Bright adaptado para tema Omega Drakon (Preto Profundo #0A0A0A / Azul Elétrico #0088FF)
  • Navegação: Scroll para zoom, arrastar para mover, Shift+arrastar para rotacionar
  • Offline: Tiles podem ser baixados como .pmtiles para uso totalmente offline
  • Fonte: ProtoMaps · MapLibre GL JS (Apache-2.0)
Contexto

Da Decisão do Nômade

Origem

Project NOMAD

O Project NOMAD incluía ProtoMaps como container Docker para mapas offline. Na análise de absorção (12/10), o dono decidiu: "ProtoMaps vira tarefa de dev (página de mapa, não é container)".

Implementação

MapLibre + PMTiles

MapLibre GL JS renderiza tiles vetoriais ProtoMaps (.pmtiles) no navegador. Sem backend, sem container — apenas arquivos estáticos. Funciona via Tailscale Funnel ou localmente.

Tiles

Fontes de Tiles

Tiles base: ProtoMaps OSM (atualizados semanalmente). Para offline, extrair o recorte regional em .pmtiles (Brasil: estimativa de 1–3 GB — medir antes de baixar) e colocar em /site/maps/brasil.pmtiles.

Integração

Futuro no OmegaDrakon

Esta página pode evoluir para: marcação de peças do Registro Mestre no mapa, visualização de sensores IoT (Home Assistant) com geolocalização, rotas de campo para Living Systems/FAB.
