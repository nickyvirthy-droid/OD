Privatizar o repositório

"Repo" (repositório) é a pasta onde vive o código-fonte do Omega Drakon, hospedada no GitHub. Hoje ela está pública: qualquer pessoa no mundo que tenha o link abre e vê todo o código e todo o histórico — commit a commit, desde o primeiro dia. Abaixo está o que isso significa, o que muda se você privatizar, e o botão.

O que está exposto hoje

Nenhum segredo vivo: os que vazaram foram rotacionados em 17/10 — o que está no GitHub agora é valor morto. O que continua exposto é o código: quem abrir o link copia o projeto inteiro se quiser. E o risco futuro é esse: qualquer deslize (um segredo cometido sem querer num commit) já nasce público na hora.

O que muda — e o que não muda

Privatizar não apaga nada: é o mesmo lugar, a mesma história, os mesmos commits — só muda quem pode ver (você, e quem você convidar). Nada quebra: o app, o site, o painel, as atualizações, os backups e as ferramentas não dependem do GitHub — conferido no código, nada é baixado daqui em produção. E é grátis.

O único efeito colateral (honesto)

O CI — as verificações automáticas que rodam a cada envio — é grátis em repo público. Em repo privado ele consome os 2.000 minutos grátis por mês do GitHub, e o uso atual é ~4.300 min/mês (57 execuções/dia × ~2,5 min, medido desde 13/10): estouraria. Duas saídas, as duas resolvo eu: (a) recomendada — monto o CI no seu servidor (self-hosted runner, grátis, mesma suíte do gate); (b) desligo o workflow do GitHub e a suíte local continua sendo o gate, que já é a regra da casa antes de cada commit.

Abrir as configurações do repo
  1. Clique no botão acima (vai pedir o login do GitHub, se ainda não estiver).
  2. Role a página até o fim, na seção vermelha Danger Zone.
  3. Clique em Change visibility → Make private.
  4. Digite nickyvirthy-droid/OD para confirmar. Pronto.

Depois disso o link só abre para você (e para quem você convidar). Se um dia quiser voltar a público é no mesmo lugar, no mesmo botão. Aviso: você pode me mandar "privatizei" e eu confirmo daqui pela API em 5 segundos.
