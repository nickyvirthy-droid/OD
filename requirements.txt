# OMEGA DRAKON — dependências externas (o restante é stdlib puro)
#
# A versão do sistema é mantida em OD_VERSION (.env). Veja core/capabilities.py.
# Instale na venv do projeto:
#   .venv/bin/pip install -r requirements.txt
#
# 1) Driver PostgreSQL puro-Python — backend PostgreSQL da Database Layer
#    (storage/database.py).
pg8000>=1.31
#
# 2) google-auth — push FCM (core/push.py). O FCM HTTP v1 exige OAuth2 com
#    JWT RS256 assinado pela service account do Firebase; o google-auth faz a
#    troca por access token e a renovação. NÃO traz cliente HTTP próprio: o
#    projeto continua usando urllib do stdlib (adaptador UrllibRequest).
#    Sem ela, o push fica dormente (import tardio, nada mais quebra).
google-auth>=2.0
#
# 3) websockets — servidor de streaming token-a-token do chat
#    (integrations/api/ws_server.py, porta OD_WS_PORT, padrão 8001).
#    É o ÚNICO servidor que não é stdlib: a API REST continua em http.server.
#    Usa a API moderna (websockets.asyncio.server.serve, exige >=14); o import
#    é tardio e a falha fica contida, então sem ela o núcleo sobe normal e só o
#    streaming fica indisponível.
websockets>=14.0
