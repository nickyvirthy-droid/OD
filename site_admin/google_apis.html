Habilitar as APIs do Google

Drive · Agenda · Gmail — a autorização OAuth já foi concluída; falta ligar as 3 APIs no projeto 582855984584.

Em cada página aberta, clique no botão ENABLE (ou Habilitar). Se pedir login, entre com a mesma conta Google autorizada. Não há nada para copiar — só clicar.

Os 3 botões

  1. ① Enable Gmail API
  2. ② Enable Calendar API
  3. ③ Enable Drive API

Depois de clicar nos 3

  1. Espere ~1 minuto (propagação do Google) — não precisa reiniciar nada no servidor.
  2. Voltar ao chat e digitar "APIs ligadas" — o servidor refaz a prova viva (e-mails, agenda, drive).
